DCS RYZEN Copilote — le copilote de combat vocal pour DCS World.

Il connaît toutes les commandes de ton avion, il les exécute, et il affiche la touche
à presser dans un carré posé par-dessus le jeu. Son cerveau tourne en local sur le NPU
Ryzen AI : aucune clé API, aucune donnée envoyée sur Internet.

⏱ CHAPITRES
00:00 Présentation
00:16 Il exécute les commandes de ton avion
00:37 Le dossier de 9 pages
00:52 L'IA locale sur NPU Ryzen AI
01:06 Ton instructeur à bord (F-14 : menu Jester)
01:23 Open source sur GitHub
01:37 Bon vol

✨ CE QU'IL SAIT FAIRE
• « sors le train » → Maj+G, « active le master arm » → M, volets, aérofreins, crosse, perche
• « montre-moi les volets » → il affiche la touche, sans rien actionner
• Pilote automatique : maintien d'altitude, assiette, palier, altitude + cap, débrayage
• F-14 : il ouvre le menu Jester, choisit l'entrée (Ctrl+1…8) et referme — chemins mémorisables
• Instructeur : décollage, atterrissage, combat, une étape à la fois
• Il fait apparaître cibles, menaces et renforts, marque une position, ordonne aux alliés

🧠 100 % LOCAL (possible)
• Voix : Piper (9 voix) · Oreille : Whisper · Cerveau : Qwen 3.5 4B sur NPU Ryzen AI
• Les commandes de l'avion sont reconnues sans IA (0,2 s) : elles marchent même si le modèle est arrêté

🔗 PROJET (open source, licence MIT)
https://github.com/ericboul/dsc-ai-deepseek-v.1.01

📄 Dossier PDF (9 pages), fiche rapide, référence des commandes vocales et journal des
versions sont dans le dépôt, dossier /docs.

👤 Créé par Eric Boulianne — développeur web & graphiste.
